# Security

## Reporting a vulnerability

Email `security@decdn.org`. Please do not open a public issue for security
reports.

This repository holds a demo browser extension for `decdn gateway`. A report
about the gateway, the protocol, the SDK or the node belongs to
[decdn/decdn](https://github.com/decdn/decdn), which carries the full
[security policy](https://github.com/decdn/decdn/blob/main/SECURITY.md).
